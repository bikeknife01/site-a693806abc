## Defects and assumptions to harden

1. **Read-only contract failure:** Windows handle includes write rights; `write<T>`, `writeBytes`, `hostWr_`, and `physWr_` exist (L342–360, L667–698, L1489–1502). Remove write path at compile time and assert the requested access mask in tests. A facade alone is insufficient.
2. **Partial reads:** `readBytes_` writes successive pages to caller memory before all pages succeed (L1474–1487). Return a distinct partial-read error and no usable bytes unless explicitly opted into a bounded diagnostic mode.
3. **Memory safety:** arithmetic in `readString`, chains, VA increments, bank offset plus length, and ELF section/program-header calculations needs checked addition/multiplication (L361–424, L674–686, L950–1000, L1474–1502, L1624–1650). Test malformed inputs with sanitizers and fuzzing.
4. **Identity:** no proven one-to-one instance→VMM→guest process link, and `alive()` is weak. Cross-check at each acquisition generation; never pick the biggest process.
5. **Scan cost and false positives:** candidate caps (`kMaxCands=400000`, 128 MiB chunk cache, 128 MiB table contents at L546–552) limit memory but can silently truncate discovery. Record truncation and reject ambiguous matches. Discovery scans broad guest RAM once; no long-running cadence may depend on repeating it frequently.
6. **Build:** MIT license (`LICENSE`); header-only Win32 + STL + Advapi32. Upstream `build.bat` targets C++17 with MSVC or MinGW, not CMake/C++20. The example is diagnostic only; compiling does not prove safe or correct reads.
7. **Privilege and introspection:** `enableDebugPriv_()` does not verify `ERROR_NOT_ALL_ASSIGNED` after `AdjustTokenPrivileges` (L618–632), and `pid()`, `cr3()`, `error()` and `splitRamSuspected()` read mutable state without locking (L455–479). A hardened fork should avoid mutable shared introspection and use a privilege request only when a documented test requires it.

## Recommendation

Choose **B: a small read-only fork** for M1. Preserve the source revision and MIT notice. Strip write operations and write permissions, disable automatic debug privilege, replace implicit PID selection, add checked errors/bounds, and add mockable host-read interfaces. Reuse of the original unchanged fails the stated read-only requirement. A full clean-room provider (C) is premature until the translation algorithm is validated; move to C if the fork proves too coupled or incompatible.
