# Season 1 Atlas source

This map was rebuilt on 2026-10-16 from retained local `Westeros_Alpha_6_*` client resources using the current Atlas extraction pipeline. Its 7,694 POI rows and historical region, kingdom, and crossing outputs match the Alpha artifacts preserved in Git history.

The retained source resources were not part of the repository, so this folder contains the generated interactive map and its three image assets for static publication. Client resources establish installed content, not live server activation. The source region bitmap ended 57,428 pixels before the declared map extent; those trailing pixels render as zero/ocean and should be visually reviewed before publication.
